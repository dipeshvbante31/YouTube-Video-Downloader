# 🎥 YouTube Video Downloader

A simple Python-based YouTube video downloader using **yt-dlp**.

This project allows users to download individual YouTube videos directly from the terminal.

## 🚀 Features

- Download YouTube videos using a URL
- Saves videos automatically inside the `downloads/` folder
- MP4 format when available
- Prevents playlist downloads
- Simple command-line interface
- Error handling

## 🛠️ Technologies Used

- Python
- yt-dlp
